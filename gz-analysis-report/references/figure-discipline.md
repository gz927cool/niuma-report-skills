# 插图质量纪律

> 条件加载：报告含插图时使用本模块——按可出版标准自查五条纪律，各条均来自真实返工。


- **元素必要性审计**：图内每个标注问"是什么、是否必要"；一句话能说清的定义
  移到正文图注，不在图里挤说明；信息与其他元素重复的标注删，删后收紧画布
  不留空带。
- **文字不压线不重叠**：标注之间、标注与曲线之间不得重叠穿字；发现冲突给
  最小修复（如加空格让虚线从缝隙穿过）。
- **动态特性用真实数据**：机制含时变行为（如带宽随行情收窄/放宽）时，用真实
  数据窗口呈现该特性，不画静态示意。
- **多面板对齐**：多子图的上下边缘跨面板对齐，构图不留大片空白。
- **正式产出不带内部标记**：协作人名、本地代号等内部标记不进报告与图，只留
  在代码层。

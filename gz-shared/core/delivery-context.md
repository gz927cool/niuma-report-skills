# 交付语境分层

> 条件加载：报告用于对外交付/合同场景时适用。内部读者的报告按研究形态执行。

同一份"诚实"在不同场景有两种合法形态，底线只有一条：**绝不把未实现写成已实现**。

## 研究形态

- 负结果与缺口直陈：负结果同权重，未实现的内容如实写方案现状，不装作已解决。
- 确无数据/未实现的内容不立占位章，研究稿进"待澄清"清单或直陈。

## 交付形态

- 结果类负结果仍如实报数（不软化、不编造）——数字诚实不因场景改变。
- "未实现/未接线"类范围缺口不写认错式清单，改用正面框架带过（"同时输出，提供综合参考""留作标定项""可经配置接入"）。

## 场景判定

以用户声明的报告用途为准；未声明且判断不了时，先问一句再动笔。

# 数字纪律

> 供数据分析/通俗版报告技能引用的数字规则。Why：读者无法自行核数，软化一个数字、漏掉一个基线，报告就从"信息"变成"立场"。

- **实际算出来再写**：关键数字、对照锚点、数据概况（峰值、区间、涨跌幅）必须实际算出来，不凭印象写；背景中的实证依据（规律、相关性）在本次数据上现算——沿用旧数字，数据和口径一换就成了虚构引用。
- **口径一致，不写新旧对照史**：同一数字全文口径一致；只写当前口径，不出现"相比旧版/旧模型的改进"式叙述，不引用已废弃实现。
- **先出现再引用**：结论段引用的每个数字，正文必须先完整出现过。
- **负结果同权重**：没起作用的因子、没通过的检验、失效的方案，与正面结果同权重呈现；50% 就是 50%，不写"差一点没过"。
- **对照锚点**：关键比例类指标必须给出对照锚点（名义值/朴素基线/抽样波动正常范围），不单边呈现裸比例——单边行情、不均衡样本里，裸比例会被基线明显抬高。
- **机制可复述**：核心机制要写到"数是怎么算出来的"（步骤+例子），让读者能复述"这个数从哪来"；对话里讲明白了但文档没写的，回填进文档——读者没看懂，责任在文档不在读者。
